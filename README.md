О проекте
=========

Редактор графов, разработка начата в образовательных целях.

Структура проекта
-----------------

Два подпроекта:

* __edgelib__ — независимая header-only библиотека алгоритмов
    - edgelib/include/edgelib — расположение заголовочных файлов библиотеки
    - edgelib/tests — расположение модульных тестов библиотеки (DocTest)
* __edgegui__ — приложение с графическим интерфейсом на основе Qt и edgelib
    - edgegui/include — расположение заголовочных файлов редактора
    - edgegui/src — расположение единиц трансляции редактора (cpp-файлов)
    - edgegui/tests — расположение модульных тестов для тестируемой части редактора


Используемый стек технологий
============================

ISO C++23 (без модулей), Qt 6.8, CMake 4.0, DocTest 2.5
